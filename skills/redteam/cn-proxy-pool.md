# 换出口 IP（判断值不值得，以及底线在哪）

免费代理不稳定，它的定位是**降低被封的风险**，不是隐藏身份。关键目标优先用自有出口或隧道。

## 铁规则：不动本机的网络与代理配置

代理**只允许在单条命令上临时指定**。以下一律禁止：

| 禁止 | 说明 |
|---|---|
| 设系统代理 | Windows「网络和 Internet → 代理」、`netsh winhttp set proxy`、PowerShell 的全局代理设置 |
| 写全局环境变量 | 系统级或用户级持久化的 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY，包括 shell 配置文件里的永久 export |
| 改工具全局配置 | curl 的配置文件、npm/pip/git/docker 的 proxy 项、浏览器代理设置 |
| 起代理隧道进程接管流量 | 任何把本机全部流量导向第三方的做法 |
| 动系统网络 | 路由表、DNS、防火墙规则、VPN/虚拟网卡 |

**正确姿势**：代理参数直接写在**这一条**命令上，进程结束即失效。工具不支持代理参数时，
用一个最小的本地转发（把单个端口映射出去），而不是改全局配置。

## 判据：换了代理之后，有效还是无效

| 信号 | 含义 | 动作 |
|---|---|---|
| 换 IP 后同一请求从 403 变 200 | 之前是 IP 级封禁 | 继续用轮换，但降低请求频率 |
| 换 IP 后仍然 403/429 | 封的是账号、Cookie、指纹或行为特征 | 换 IP 没用，停止折腾代理，改手法 |
| 代理响应时间忽高忽低、大量超时 | 免费代理质量差 | 降并发，或只对低价值请求用代理 |
| 目标对所有来源返回同样的拦截页 | 有统一 WAF 策略 | 换 IP 无效，转低速率单点探测 |
| 通过代理发的请求拿不到真实回显 | 代理篡改或拦截了内容 | 立刻停用，重要请求不要走免费代理 |

**核心判断**：**IP 只是挡在前面的第一层**。被封往往是因为行为（频率、UA、路径规律），
换 IP 只是买时间；真正的解法是降速和改请求特征。

## 什么请求绝对不能走免费代理

- 携带凭据、Cookie、会话令牌的请求；
- 上传 WebShell 或任何落地文件的请求；
- 隧道本身（隧道走免费代理既不稳又不安全）；
- 任何能被举报/追溯为"某个人"的操作。

## 轮换与限速的实际做法

1. **先降速，再加代理**：很多封禁在降到低频后自然消失，加代理只是白折腾；
2. **同一目标连续被封就放弃**（记录状态），不要在同一个入口上反复换 IP 硬打；
3. 代理失败要能**自动剔除**，不要一条命令因为选到坏代理就误判"目标不存在"；
4. 用完清掉本地临时文件，不在系统里留下任何代理痕迹。

## 纪律
- 只在本次范围内使用；免费代理可能记录流量，视为不可信通道；
- 高频爆破前先确认目标没有账号锁定策略，触发锁定前主动停手；
- 优先级从高到低：自有出口 / 已建隧道 / 降低频率 / 免费代理。
