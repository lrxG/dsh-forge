# 对象与租户（换 id 到底换什么）

**换 id 不是换一个参数，是换一个"归属"。** 能圈人、圈物、圈租户、圈文件的参数都算对象：
数字序号、UUID、密文 id、手机号、租户号、门店号、站点 id、附件 key。

## 判据：什么算越权成立

| 差分 | 算成立 | 不算 |
|---|---|---|
| 换成邻号后回包出现他人的姓名/手机/证件/正文 | 越权读 | 回包仍只有自己的；换成不存在的 id 也回同样内容（那是公开数据） |
| 列表换租户/门店/`0`/`-1` 后出现他租户单据 | 越权读（跨租户） | 只在自己租户内多出几条 |
| 批量参数 `ids=1,2,3` 里有他人的、且真返回 | 批量越权 | 接口忽略多余 id |
| 上传/导出带上他人的对象 id 且成功落地 | 越权写/越权导出 | 只回 200 但库里没变 |
| 多塞页面没显示的控制字段（角色/租户/余额/审核状态）后状态真变 | Mass Assignment | 字段被吃但权限不变 |

**唯一标准：比基线多了"谁的什么"**。只说"返回 200"、"字段被接受"、"' 号报错"都不算。

## 怎么跑差分（不用肉眼比两段正文）

基线与对照各发一次，比较三样：**状态码、字节数、关键字段**（长度相同但字段不同也算差异）。

```bash
python httpprobe.py -b https://TGT -p /api/orders/1001 -p /api/orders/1002 --diff --no-proxy
```

- 先看两条的 `status` 和 `len=`；相同再读 `--diff` 的 unified diff。
- 判据：出现他人字段/他人 id/条数变化 = 成立；只有时间戳、随机 nonce、请求 id 不同 = 不算。
- 把两次请求与响应分别用 `http_evidence_add` 落到同一个 vuln_id（A/B 两条），报告里能对照。

## 要跟到的层级

列表 → 详情 → 附件/导出/下载 → 审批/流转 → 关联对象。**父对象做了鉴权，子对象常常没做**：
列表过了不代表附件过了，详情过了不代表导出过了，每条都要单独换一次 id。

## 写越权的最小伤害顺序

1. 先证明能写：把自己的对象挂到别人名下（能不能加）；
2. 再删掉自己刚加的那一条（证明可逆）；
3. 不改、不删别人已存在的订单/地址/口令/角色；
4. 改密/改绑类只验证"拿掉旧校验这一步过不过"，过了立刻改回；改不回就停在回包，不再动；
5. 扣款、清库存、批量删除一律不做。

## 换路条件

- 换号后所有接口都回同一句"请登录"、且没有条数/长度/耗时差分 → 这是同一道闸，转别的面；
- 换号后 `total` 恒为 0 且无稳定差分 → 证伪，换下一条，不要磨到出数；
- 缺第二个对照号时，用邻号、回包里抄来的 id、`0`/`-1`/空，不要为了凑号去磨注册或验证码；
- 前端把 id 加密了（JSEncrypt/公钥），用页面里的公钥加密邻号，而不是放弃这条。

## 执行位置
本机经代理发；有会话就带会话发。不要把"未登录也能出"和"换了 id 出别人的"混成一条结论——
前者是未授权，后者是越权，记分口径不同。

## 落库
每条越权记独立漏洞（带目标、参数、回显）；能登录的账号记凭据条目；
证据留原始请求与响应片段（面板用 http_evidence）。
