# WebShell 交付（重点是"用户能不能用"）

## 判据：什么才算交付

**用户要能在自己的客户端里直连这个入口**，所以交付物只能是**加密马**（冰蝎/哥斯拉那一类），
并且必须把连接密码一起落库。

| 落地的东西 | 算不算交付 | 理由 |
|---|---|---|
| 冰蝎马 / 哥斯拉马（加密流量） | **算** | 客户端能直连、能开虚拟终端、能当隧道入口 |
| 一句话马（`?cmd=`）、自研马 | **不算** | 用户无法交互操作，只能当临时中转，且 note 里必须写明"临时中转，非交付入口" |
| 内存马 | **不算** | 随进程消失，用户拿不到入口 |

**落地失败的判据**（出现任一就换路，不要反复上传）：

| 信号 | 含义 | 换什么 |
|---|---|---|
| 上传成功但访问返回源码原文 | 目标没解析该后缀 | 换语言（JSP→JSPX、PHP→phtml）或换后缀 |
| 访问 200 但响应体与正常文件无差异 | 被 WAF 拦下并返回了替代页 | 换编码变体（unicode 转义）、换上传点 |
| 上传后几秒内文件消失 | 有主动查杀 | 换更隐蔽的写入点（模板目录、日志包含），或改走命令执行 |
| 连续两处上传点都被清掉 | 站点有整体防护 | 停止落地，改用已有的命令执行做一次性动作 |

## 生成加密马的关键点

冰蝎马的密钥就是**连接密码的 md5 前 16 位**，模板里那串默认值对应的是官方默认密码——
**用默认密码等于把入口交给防守方**。生成时要：随机密码 → 算密钥 → 替换模板 → 记下密码与密钥。

模板按目标语言选：JSP 系（含 java9 变体）、PHP、ASPX/ASHX、ASP。目标是 Java 站就选 JSP 系，
不是所有站都能跑同一份马。目标有查杀时优先用 unicode 转义变体。

哥斯拉马需要 GUI 生成，人在场时可用；我在无人值守时优先走冰蝎的无 GUI 生成路线。

## 判据：什么算"能用"，什么只是"能访问"

| 观察 | 结论 |
|---|---|
| 客户端能建连、虚拟终端能回显、能开文件管理 | **能用**，算交付 |
| 浏览器访问 URL 返回正常，但客户端连不上 | **只算能访问**：多半是密码/密钥没对上，不是马没落地 |
| 用带明文命令参数的 GET 能回显 | 这是临时中转，不是加密入口；加密马本来就不响应明文命令，别拿它当"能用"的证据 |
| 文件在，访问 404 或返回源码 | 没解析该后缀，等于没落地 |

落地之后的价值判断只有一条：**用户能不能用他自己的客户端接手**。不能接手就只是你的一次性动作，不该记成交付物。

入口一旦确认可用，接着就是隧道——WebShell 是入口，进内网要靠 `suo5-tunnel`。

## 典型失败原因（按概率排）

- 后缀不被解析（目标只认特定后缀）→ 先探清目标认哪些后缀，再决定用哪种马；
- 密码/密钥没换（用了模板默认值）→ 检查密钥是否真的替换成功；
- 目录无执行权限 → 换到确定能执行的目录（已有的上传目录、静态资源目录）；
- 写入内容被转义或截断（上传点做了过滤）→ 换编码形态再落地。

## 纪律
- 只落到本次范围内的目标；用完按需清理，恢复原状；
- 落地失败时两三次不通就说明这条路对当前目标不通，换思路；
- 马与密码属于凭据，落库即可，**不要写进报告正文与对话**。
