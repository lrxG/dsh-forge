# 命中之后（真的还是像）

扫出来的东西里，大部分是统一错误页。这一篇只解决两件事：**这个命中是不是真的**、**拿到之后下一步是什么**。

## 按类型判（先确认，再跟进）

| 命中 | 算真的 | 只是像 | 下一步 |
|---|---|---|---|
| 后台 / 管理入口 | 有登录表单、有独立资源、标题与业务对得上 | 302 到统一登录、或全站同一个错误页 | 默认口令与弱口令，见 `credential-attack` |
| 源码与版本库 | 能取到仓库元数据与对象、能还原出代码 | 目录列表 403、或只有一句"forbidden" | 还原源码找第二层入口（硬编码、配置、调试开关） |
| 配置与备份 | 内容有键值、连接串、账号 | 空文件、模板占位、乱码 | 连接串与账号分别验证，见下 |
| 接口文档 | 能列出真实接口与参数 | 只有标题页或示例 swagger | 全量接口清单交给 `exposed-services` / `object-and-tenant` |
| 监控 / 运维台 | 面板能读出运行数据 | 只有登录页、或提示无权 | 未授权读数按漏洞记，能改配置的按高危 |
| 上传 / 导入 / 备份恢复 | 能传、能选路径或能指定来源 | 只有前端按钮、接口拒绝 | 交给利用链，别单独当漏洞 |
| 私钥 / 证书 | 私钥能配上对应服务 | 公钥、仅证书、过期作废 | 尝试登录一次；失败就记凭据不再试 |

## 泄露物怎么用（别把"拿到"当"打穿"）

- **连接串**：先只做一次连通性验证，确认库存在与账号有效；不写数据、不改配置。拿出来是成果，动它是越界。
- **密钥 / AK**：验证它能做什么（读？写？列？），验到能列出他人资源即成立；验不了就只记"疑似有效"。
- **口令**：能登上对应服务才算成立；同一个口令只在验证过一次的服务上落库，不要批量试其他系统（撞库式扩散会触发封禁）。
- **源码**：这是最值钱的一类——找硬编码密钥、内部接口、调试开关、未上线的管理功能，往往比当前站点更值。
- **配置里的路径与内网地址**：记进资产拓扑，交给 `fscan-intranet` 作为内网入口线索。

## 反幻觉

- 一份 `.zip` 打得开但里面是图片与静态资源 → 不是源码泄露；
- `.env` 里有键但值是 `changeme` / 空 → 记"配置泄露"，不要当凭据；
- 目录列表能看但没有任何敏感文件 → 只记"目录列举"，低危；
- 命中的"后台"如果没有第二个可访问的功能页 → 多半是遗留页面，不要按管理入口定级。

## 换路条件

- 连续几个"命中"都是同一张错误页 → 回到 `dir-bruteforce` 修基线；
- 泄露物验证一次不通过 → 记事实，不要换着法子反复试同一份凭据；
- 页面有蜜罐特征（唯一 ID、诱饵路径、异常跳转）→ 停手记线索，不要继续深入。

## 落库

入口写进资产 `surface`；泄露的源码与配置写凭据（来源写清"配置泄露"）；可读的未授权接口写漏洞并附原始报文；
私钥、AK 这类属于凭据，落库即可，**不要写进报告正文**。
