# 域渗透

域不是"又一层内网"，是**一个身份体系**。拿到一台主机的本地管理员，和拿到一个普通域账号，
能走的路完全不同。判断始终落在同一句话上：**我这个身份，在这个域里能读到什么、能改什么**。

## 先分清手上是什么

| 手上 | 能做的 | 走不通的 |
|---|---|---|
| 无凭据，只有内网可达 | 定位域控与成员机、找匿名可读的共享与目录服务 | 任何需要域身份的查询 |
| 一个普通域账号 | 枚举用户/组/计算机/服务主体、找可破与可离线破的目标 | 直接读域控 |
| 一台域内主机的本地管理员 | 取该机内存里的凭据、看它的服务账号与计划任务 | 域内其它主机 |
| 域管理员或可控域控 | 全域 | 该收了 |

**最常见的高估**：把"拿到一台主机的管理员"当成"拿到域"。判据是**这台机上有没有域内高价值身份登录过**
（服务账号、备份账号、有人拿它管域控）。没有，就只是多了一台机器。

## 值得往下打的信号

| 信号 | 含义 |
|---|---|
| 能枚举到一批带服务主体的账号 | 能请求票据就能离线破，不需要再碰目标 |
| 某些账号对机器有委派权限 | 拿到该账号等于拿到它委派到的那些服务 |
| 域内有证书服务，且模板配置宽松 | 错配的模板等于直接发身份，比破口令稳 |
| 邮件或协作系统与域集成 | 常常是拿第一批域账号的地方 |
| 同一口令在多台机器上可用 | 本地管理员口令复用，横向成本骤降 |
| 域内主机长期没重启、补丁落后 | 已公开的提权与远程执行有位置 |

**假路**：只有一个域账号但查询被限制、能读目录服务却读不到关键属性、服务账号口令策略极强、
以及"能连 445 但拒绝认证"——这些都不是进去了，只是能碰到端口。

## 收敛与止损

- **改配置、加账号、动组策略都会留痕**，域内日志是集中收的：一旦开始改，就假定对方看得见。
- **离线破与在线试要分开算**：前者不产生失败记录，后者会触发锁定。先确认锁定策略，命中即停。
- **能同步目录哈希的权限就等于结束**：继续刷主机只增加暴露。
- 拿到域控后别急着再扫全内网——先把已有入口、凭据、可达段交代清楚，比多扫十个网段有用。
- 打不动就退回**成员机侧**：本地凭据、计划任务、共享、已装软件的服务账号，通常比硬刚域控便宜。

## 落库

域内身份单独记：账号、能登录哪些机器、属于哪些组、口令从哪来。主机记"谁能登它"，不是只记端口。
拿到域控、域管、目录同步这类权限，按得分口径写进漏洞的 `gained`，否则报告里这条链是断的。
