# APK 破解

## 路线

勘察（类型/壳/入口）→ 反编译取源码与 smali → 定位授权判断 → 改判断 → 重打包 → 重签名 → 安装验证。

工具按本机实际位置调用，不照抄别人机器上的目录：apktool / jadx / adb / 签名工具，缺哪个先装。

## 判断要点

- 授权点多在登录态、VIP 标志、卡密校验、到期时间；Java 层与 smali 层各确认一次。
- 签名自校验（读自身签名做比对）要单独定位，否则装了却启动即退。
- 网络二次校验（服务端验卡密/签名）本地改不动，只能抓包看响应。
- 加固壳先分类：轻壳可脱，重壳按卡点处理——脱不动就上报，不在脱壳机上耗。

## 判据

- 三件事同时成立：**装得上、起得来、功能真解锁**。少一件都只是半成品。
- 反幻觉：界面显示 VIP 但请求仍被服务端拒，是只破了皮；装上了却启动即静默退出，多半是签名自校验没过；改提示文案不等于逻辑改了。
- 同一份授权逻辑可能在 Java 层、smali、so 里各有一份，改完要确认运行时走的是改过那条。
- **换路**：加固壳脱不掉时作为卡点上报，不在脱壳机上无限耗。
