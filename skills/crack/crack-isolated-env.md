# 隔离环境

## 划分

- **跑样本、调试、注入**放隔离环境；**纯静态**宿主机即可。
- 三件套：**断网 + 快照 + 可丢弃**。
- PC 样本用 Windows 虚拟机或系统沙盒；安卓用模拟器或专用测试机。

## 判据

- 三件事同时成立才算就绪：**断网、有快照、能回滚**。
- 模拟器"开了 root"不等于 `su` 可用；frida-server 在跑也不等于客户端连得上（版本/架构/SELinux 任一不匹配就失败），以真连一次为准。
- 样本检测到虚拟环境就退出，说明环境本身就是它的判断依据 → 换真机或改特征，不硬在本机跑。
- 用户坚持宿主机：说清风险后照做，不再劝。

## 交付

用了什么环境、是否断网、快照点、注入工具版本。
