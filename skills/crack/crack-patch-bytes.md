# 补丁与 keygen

## 常见手法

| 目标 | 手法 |
|---|---|
| 条件反转 | 跳转条件取反（smali / x86 / ARM 同理） |
| 恒真返回 | 函数入口直接返回真值 |
| 试用重置 | 定位到期判断或写入点，置未来时间或跳过写入 |
| 字符串替换 | 失败提示换成成功串，需配合跳转 |
| 服务端校验 | 本地恒真只能骗界面，先抓包确认有没有二次校验 |

APK 改完要重签名（apksigner 优先，jarsigner 兜底）；.NET 走 IL 层改或去强命名。

## 判据

- 改的必须是**判断点本身**：行为差异只出现在这一项功能上，其它功能不动。
- 三条反幻觉：① 只改文案没改分支，界面变了逻辑没变；② 改了一处，另一处（服务端、备用路径、二次校验）还在；③ 补丁后能跑但功能错乱，说明偏移落在指令中间。
- keygen 的算法必须从样本里还原；只拟合已知几组输出的是查表，不是算法。
- **换路**：补丁后崩溃且不是偏移问题，先别叠加第二刀，回到定位阶段。

## 交付

可运行补丁 · 应用与回滚步骤 · 前后对比证据（hexdump/反编译片段/哈希）· 原件 `.bak`。
